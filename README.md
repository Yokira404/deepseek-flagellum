# the_cell/flagellum · 三维「鞭毛结构与运动」交互模拟器

`flagellum-3d.html` —— 单文件、零依赖、离线双击即开的**革兰阴性菌鞭毛马达三维模拟器**（中文界面）。
整个页面自包含（内联 CSS/JS，无任何 `src`/`href` 外部引用），可随意移动目录或拷到 U 盘。
3D 部分是自研的**深度排序软渲染器**（透视相机 + 球体精灵 + 真实前后遮挡），
因此断网、内网、U 盘拷贝都能直接跑。

---

## 一、快速开始

双击 `flagellum-3d.html`（推荐 Chrome / Edge / Firefox 桌面版）。

## 二、结构清单（19 个可交互构件）

自胞外向胞内：

- **分层背景**：胞外液 → 脂多糖 LPS（类脂 A + 核心多糖 + O 抗原糖刷）→ **外膜**（不对称双层 + 孔蛋白三聚体）
  → 周质空间 · **肽聚糖层**（NAG–NAM 糖链环 + 肽桥交联网袋）→ **细胞质膜**（双层 + 膜蛋白）→ 细胞质（核糖体）
- **轴系**：帽 FliD₅ → 鞭毛丝 FliC（8 根原纤维珠链 + 螺旋波）→ 钩–丝接头 FlgK/FlgL → 鞭毛钩 FlgE（53 nm 三次贝塞尔万向节）
  → **L 环 FlgH**（外膜轴套）→ **P 环 FlgI**（肽聚糖轴套）→ **杆**（近端 FlgB/C/F + 远端 FlgG，半透明以露出中空芯）
  → **MS 环 FliF**（M 环 + S 环）→ **C 环**（FliG·FliM·FliN，剖开钟形）
- **动力与输出**：**MotA₅MotB₂ 定子 ×11**（固定不动，MotB 有两根锚定连线扎进肽聚糖层）、
  H⁺ 沿定子通道下行 → 在 MotA–FliG 界面闪出**力矩火花**并点亮对应 FliG 亚基、
  **输出装置** FliP₅FliQ₄FliR + FlhA₉/FlhB（T3SS 核心）、**FliI₆ ATPase** + FliH/FliJ（ATP 闪光）、
  flagellin 亚基沿约 2 nm 中空通道由输出门经杆芯 → 钩 → 丝上行到帽下装配（每到达一个，帽闪光、丝变长、计数 +1）

## 三、两个要求的功能

**爆炸图**：滑块 0–100% + 「展开/合拢」按钮 + <kbd>E</kbd>。按"胞内 → 胞外"轴向次序分离 14 个层级
（FliI₆ → 输出装置 → C 环 → 细胞质膜 → MS 环 → 杆 → 肽聚糖 → P 环 → 外膜/LPS → L 环 → 钩 → 接头 → 丝 → 帽），
定子额外**径向外移**以露出与 FliG 的齿合界面；LPS 与外膜同组位移（它本就长在外膜上）；
相机会随分离度自动抬高并后退，避免帽/丝被推出画面。

**速度调节**：
- 「时间倍速」0.05–3.00×：缩放整个仿真时基（旋转、质子、输出、装配同步变化）。
- 「质子动力势 PMF」0.20–1.60：物理源头量，同时决定转速、扭矩、质子通量与 ATP 闪光频率；调到最低近乎停转。
- 读数栏给出真实量级（转速 Hz、扭矩 pN·nm、每圈 H⁺）并注明**动画放慢约 545×**（PMF=1、1× 时）。

## 五、渲染实现要点

- **投影**：yaw/pitch/dist 轨道相机 + 透视除法；每帧把全部图元（球 / 线段 / 辉光）投影后按视深 `vz` 降序排序再绘制 —— 前后景遮挡是真的排序遮挡，不是画法顺序。
- **球体精灵缓存**：`颜色 × 7 级景深明暗` 预渲染成小 canvas，绘制时 `drawImage` 缩放，2000–3000 个亚基仍能满帧。
- **背面剔除**：管状构件（杆/钩/丝）按法线与视线点积剔除背面珠子，半透明管壁下仍能看到内部上行的亚基。
- **相机朝向剖切**：膜片 / 肽聚糖 / C 环 / 定子按方位角挖掉朝向相机的扇形楔块，所以无论转到哪个方位，内部始终敞开可见（定子只挖最前面 1–2 个）。
- **标注**：投影锚点 → 折线引线 → 左右分侧 + 防重叠排布；分层带用两侧轮廓点连成虚线并标层名。
- 「亚基密度」三档（精细/标准/流畅）重建静态层并联动 DPR，右侧实时显示 fps。

## 六、科学性说明

几何按真实量级但作了教学压缩：鞭毛丝实长 5–10 µm、含 2–3 万个 flagellin，图中只画约 2 圈螺旋；
转速真实 100–300 Hz、近失速扭矩 ~10³ pN·nm、每圈约 1000–1200 H⁺。

- **转子** = C 环 + MS 环 + 杆 + 钩 + 丝；**定子** = MotA₅MotB₂（8–11 个，锚定肽聚糖故不动）；**轴套** = LP 环。
- 按题目要求各环（含 L/P 环）默认同步旋转；但严格来说 **LP 环是不旋转的轴套**，勾选「LP 环轴套模式」即可切到严谨表现。
- MotA₅ 绕 MotB₂ 自转的 cryo-EM 新模型写在定子详情卡里，动画为清晰起见让定子完全静止。
- CW（tumble）时鞭毛丝螺距/半径收缩以示意 normal → curly 多态转变；手性未做翻转（避免中途出现"直杆"假象），详情卡中已注明。

## 七、验证记录

本文件除人工检查外，还通过三层自动校验（脚手架为一次性，未留在目录中）：

1. **DOM 桩帧循环**：注入 canvas/DOM 桩执行真实帧循环 ~700 帧，遍历全部按钮/滑块/复选框/视角/拖拽/滚轮/命中测试，无异常、无 NaN 坐标。
2. **结构性几何校验**：按材质色指纹反推每个构件的屏幕位置，断言层级次序
   `LPS→外膜→肽聚糖→细胞质膜→细胞质`、轴向次序 `帽→丝→钩→L环→P环→杆→MS环→C环→FliI₆`（爆炸态 15 项次序另测）、
   MotA 位于膜层、MotB 结合域贴合肽聚糖层、19 个构件均可拾取。
3. **动力学与真实像素**：DFT 主频测得丝 0.540 Hz / 钩尖 0.548 Hz（设定 0.55 圈/秒，Δ0.008 Hz → 同一转子同步旋转）；
   无头 Edge 实拍截图后解码 PNG 像素，按色相族统计验证默认/爆炸/特写三种状态的分层次序与构件可见性。
